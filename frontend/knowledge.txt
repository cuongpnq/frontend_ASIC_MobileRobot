user mode, access, role, login, password, switch mode, account:There are 3 user modes:\n\n- USER (default): Access to Direction, Presentation, Q&A, and Settings.\n\n- ADMINISTRATOR: Full access to all views including Control Center. Login via Settings → Switch Mode.\n\n- DEVELOPER: Reserved for advanced system access. Login via Settings → Switch Mode.\n\nThe system automatically reverts to User mode after 3 minutes of inactivity.
