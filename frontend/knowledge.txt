## Application Guide
The robot runs a touch-screen application with the following views:

1. **Direction View** — The main navigation screen. Tap checkpoints on the map to send the robot to that location. You can switch between floors and maps. A "Home" button sends the robot back to its starting position.

2. **Presentation View** — Upload and display slide files (.pptx) or text files (.txt) from a mobile phone by scanning a QR code. The robot can render slides on screen.

3. **Control Center** — Monitor robot sensor data, behaviors, and system status. Also provides access to system diagnostics and map settings. Requires Administrator access.

4. **Settings** — Manage Wi-Fi connections and switch user modes.

5. **AI Chat (this view)** — Talk to me directly on the robot's touchscreen. I run locally using a language model via Ollama.

6. **Diagnostics View** — Accessible from the Control Center. Shows real-time monitoring and historical graphs of CPU utilization, RAM usage, frame rate (FPS), network speed, and disk storage capacity.

## User Access Roles
There are 3 access levels, shown by a badge icon in the top-right corner of the screen:

- **User** (default) — Access to Direction, Presentation, Q&A, and Settings.
- **Administrator** — Full access including the Control Center.
- **Developer** — Reserved for advanced system access.

To switch roles: go to **Settings → Switch Mode**, choose Administrator or Developer, and enter the password. The system automatically reverts to User mode after 3 minutes of inactivity.
